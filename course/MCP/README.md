# Definition
* **MCP** : MCP is a protocol which enables LLM to interact with Tools


# What MCP does ?
1. Send email
2. Execute query on Database
3. Get weather data

# LLM
1. ChatGPT
2. Claude

# Tools
1. Drive API / Drive App
2. Calender API / Calender App
3. Weather API / Weather App

# Flow
```java
LLM --> MCP --> Tools
```
