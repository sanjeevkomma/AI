# ToRead
| Aspect              | Description                                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| **What it is**      | A **framework for building applications** using LLMs (like GPT) by chaining components together. |
| **Scope**           | Application-level – focuses on orchestration of LLMs, tools, APIs, memory, agents.               |
| **Examples**        | RAG systems, AI agents that use tools or memory, chatbots with long-term memory.                 |
| **Use Cases**       | Document Q\&A (RAG), personal AI assistants, coding agents, data pipelines using LLMs.           |
| **Core Components** | LLMs, chains, memory, tools (like search, code execution), agents, retrievers.                   |
| **Uses NLP?**       | Yes – it leverages NLP models and techniques to build powerful workflows.                        |
