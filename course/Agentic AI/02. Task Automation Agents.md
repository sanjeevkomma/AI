# Task Automation Agents (Focus: Breaking goals into tasks, completing them)
| AI Agent | #Purpose |
| :--- | :--- | 
| AutoGPT  | Self-running agent — completes multi-step tasks with minimal human input. | 
| BabyAGI  | Simple, fast agent — creates and manages a to-do list toward a goal. | 
| SuperAGI  | Open-source platform — create/manage multiple autonomous agents easily. | 
| Crew AI  | Build teams of agents to collaboratively complete bigger tasks | 
| LangChain Agents  | Framework to build agents that use memory, APIs, and logic to complete tasks. |
