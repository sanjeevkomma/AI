# ToRead

📌 AI Agent
– Autonomous software programs that perform one specific task.
– High autonomy within that domain, with optional memory or tool cache.
– Executes prompt-triggered goals, adapting only within its confined scope.

📌 Agentic AI
– Systems of multiple AI agents collaborating to achieve complex, multi-step objectives.
– Learns from outcomes, shares episodic/task memory & context across agents.
– Goal-initiated workflows that decompose and adapt dynamically.

📌 Functional Domains
• AI Agents → Internal enterprise search, email filtering + prioritization, autonomous scheduling, etc.
• Agentic AI → Multi-agent research assistants, adaptive game AI, intelligent robotics coordination, etc.

📌 The Key Difference
AI Agent = Think of them like a Thermostat: Responsible for a single task, which is to set a temperature
Agentic AI = Think of them as a Smart control center: ingests weather forecasts, energy prices & user schedules to orchestrate lighting, appliances & power.

📌 Architectural Evolution
AI Agent → Perception → Reasoning → Action (Beginning)
Agentic AI → Specialized agents + Shared context + Multi-agent collaboration + Orchestration + Persistent Memory (The future)

📌 Key Differences:
– Trigger: Prompt (AI Agents) vs. Goal (Agentic AI) vs. Static Prompt (Generative AI)
– Flexibility: Fixed (AI Agents) vs. Adaptive (Agentic AI) vs. Pre-trained (Generative AI)
– Memory: Optional (AI Agents) vs. Shared + episodic (Agentic AI) vs. Short-term (Generative AI)
– Adaptation: Tool tweaking (AI Agents) vs. Outcome-based learning (Agentic AI) vs. None (Generative AI)
