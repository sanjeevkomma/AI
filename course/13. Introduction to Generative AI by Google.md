# AI vs Generative AI
| #Feature  | #AI |#Generative AI |
| :--- | :--- | :--- |
| Scope | Broad, encompassing various tasks and applications (e.g., decision-making, classification, recommendation) | Narrower, focused on generating new content or data |
| Techniques | Machine Learning, Deep Learning, Expert Systems, NLP, etc.  |GANs, VAEs, Transformer Models (e.g., GPT)  |
| Applications |  Image recognition, autonomous driving, language translation, recommendation systems, etc. |  Text generation, image synthesis, music composition, video generation|
| Purpose | Perform tasks that require human-like intelligence and decision-making  | Create new, synthetic data or content that resembles the input data |

# Deep Learning Models
1. Generative Model : Generative models aim to model the joint probability distribution P(X,Y), where X is the input data and Y is the label. They can generate new data points by sampling from this distribution
2. Discriminative Model : Discriminative models aim to model the conditional probability P(Y∣X),directly mapping the input data X to the output labels Y. They focus on the boundaries between classes rather than the data distribution.
