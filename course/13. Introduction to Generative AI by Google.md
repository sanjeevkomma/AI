# Deep Learning Models
1. Generative Model : Generative models aim to model the joint probability distribution P(X,Y), where X is the input data and Y is the label. They can generate new data points by sampling from this distribution
2. Discriminative Model : Discriminative models aim to model the conditional probability P(Y∣X),directly mapping the input data X to the output labels Y. They focus on the boundaries between classes rather than the data distribution.
